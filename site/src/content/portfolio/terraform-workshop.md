## Overview

This workshop teaches developers and DevOps engineers how to define, provision, and manage cloud infrastructure using Terraform. Through practical exercises, participants gain confidence in infrastructure as code and learn patterns that scale from small projects to enterprise environments.

## What You'll Learn

- Terraform fundamentals and HCL syntax
- Provisioning and managing cloud resources
- State management and collaboration workflows
- Modules, variables, and reusable infrastructure patterns
