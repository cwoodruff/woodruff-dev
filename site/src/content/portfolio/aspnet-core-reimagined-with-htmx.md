## Overview

This book explores how htmx can transform the way you build ASP.NET Core web applications. By leveraging hypermedia-driven interactions, you can create rich, dynamic user experiences without the complexity of heavy JavaScript frameworks. It's free to read at [aspnet-htmx.com](https://aspnet-htmx.com/), and the components it teaches grew into [htmxRazor](https://htmxrazor.com/).

## What You'll Learn

- How to integrate htmx with ASP.NET Core Razor Pages
- Building dynamic, interactive UIs with minimal JavaScript
- Leveraging hypermedia as the engine of application state
- Practical patterns for real-world web applications
