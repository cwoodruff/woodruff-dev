## Overview

*Beyond Boundaries* teaches developers how to build robust, scalable network applications with C# and .NET. It starts at the socket and works up through asynchronous programming, multithreading, serialization, performance, and fault tolerance, then covers the modern protocols a distributed system actually uses: REST, WebSockets, WebRTC, MQTT, gRPC, webhooks, message queuing, SignalR, and QUIC with HTTP/3.

The book is self-published, and the companion video course extends it with .NET Aspire, modern network security, Native AOT networking, and post-quantum cryptography.

## What You'll Learn

- Socket programming and the fundamentals every higher-level protocol rests on
- Async, multithreading, and error handling in network code
- Choosing the right protocol for the job and implementing it in .NET
- Measuring and optimizing network performance
