## Overview

This workshop gives developers hands-on experience combining htmx with ASP.NET Core Razor Pages. Participants learn how to build interactive, server-driven web applications that feel modern and responsive, without reaching for complex JavaScript frameworks.

## What You'll Learn

- Core htmx concepts and how they integrate with Razor Pages
- Building interactive forms, search, and filtering
- Partial page updates and server-sent events
- Real-world patterns for production applications
