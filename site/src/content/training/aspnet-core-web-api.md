As more organizations adopt microservices and client-server architectures, the demand for developers who can build solid Web APIs keeps growing. This workshop covers the full path, from setting up your development environment to consuming the APIs you build.

You work through hands-on exercises throughout, get feedback from an experienced instructor, and collaborate with the other developers in the room.
