Build modern, interactive web applications without JavaScript framework complexity. This workshop teaches fragment-first architecture, server-driven UI, and production-ready patterns including modals, long-running operations, out-of-band swaps, SSE, WebSockets, and comprehensive testing. Every exercise demonstrates that server-rendered pages can deliver SPA-like interactivity while keeping the development model simple and maintainable.

## Why this workshop

- The fragment-first architecture pattern, introduced and applied throughout
- A production conventions module built from real-world projects
- Based on proven, delivered workshop content
